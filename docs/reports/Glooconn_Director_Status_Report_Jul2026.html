1. What is Glooconn?

Glooconn is a travel planning website. Our goal is simple: help people plan a full trip — flights, hotels, and transport — in one place, within their budget, without confusion.

Plan smarter. Travel easier. Spend less.

2. Where we are today (in plain language)

Bottom line: The product foundation is strong. Users can already search for trips, see sample results, create an account, and save trips. We are not yet showing live airline prices — that is the next major step.
~70% Overall project progress
(toward a solid working product)
~95% Core website & user account features
~10% Live travel data
(real airline connections)

3. What already works

  • Home page with a clear trip search form
  • Search results for hotels, flights, buses, and trains (sample / demo data)
  • User login (Google or email), profile page, and saved trips
  • Mobile-friendly design
  • Secure setup so future airline connections can be added safely
  • Clear project documentation and quality checks

4. What is not ready yet

  • Live flight prices from real airlines (still using sample data)
  • “Destinations” and “About” pages (links exist, pages not built)
  • AI trip recommendations (planned for later years)

5. Pace of progress

Period Focus Status
Early phase Website foundation, search form, design Complete
Mid phase Results page, accounts, save trips Complete
Recent sprint (Sprint 1) Moved search to a secure server path (needed before live airline data) Complete
Next sprint (Sprint 2) Prepare airport codes so live flights can work correctly Ready to start
Following sprint (Sprint 3) Connect first real flight data provider Planned

Pace assessment: Steady and healthy. We prioritize a stable foundation over rushing unfinished features. That reduces risk when we connect real travel partners.

6. Short-term recommendations (next 4–8 weeks)

  1. Finish flight preparation, then connect real flights — highest business value.
  2. Build Destinations and About pages — so every menu link works for demos and investors.
  3. Merge finished work into the main product line — keep one clear official version.
  4. Add a branded “page not found” screen — small polish that looks professional.

7. Long-term recommendations (2026–2030)

  1. Add hotels and ground transport from real partners after flights.
  2. Improve recommendations that match budget and travel style.
  3. Build AI-assisted trip planning (our long-term differentiator).
  4. Test with real users and refine based on feedback.
  5. Target a polished public release around 2030, as stated in project principles.

8. Risks to watch (simple view)

Risk Why it matters Our approach
Connecting live flights too early Wrong prices or broken searches hurt trust Complete preparation sprint first
Incomplete public pages Looks unfinished in demos Add Destinations & About soon
Too many parallel workstreams Slows delivery and quality One clear sprint focus at a time

9. Recommendation to leadership

Approve continuing the planned path: Sprint 2 (flight preparation) → Sprint 3 (first live flights), while scheduling Destinations and About pages for demo readiness. This balances product credibility with technical safety.
