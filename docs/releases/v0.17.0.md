# Glooconn v0.17.0 — Release Notes

**Release date:** July 2026  
**Codename focus:** Live Flights (Milestone 11 — SerpAPI)  
**Preceded by:** [v0.16.0](./v0.16.0.md) (Search Experience)

---

## Highlights

- **Live SerpAPI Google Flights** — production-capable adapter for real flight offers (dev/ops via `FLIGHTS_PROVIDER=serpapi`)
- **Full date-time mapping** — preserves `YYYY-MM-DD HH:mm` from SerpAPI (no time-only strip)
- **Currency robustness** — request / response / EUR fallbacks; unsupported codes still error safely
- **Round-trip outbound search** — round-trip queries return priced outbound options; return-token enrichment tracked for follow-up
- **Operational validation** — live smoke (11.1b), hardening (11.2), production readiness (11.3)

## Major features

- End-to-end live flights through existing architecture: UI → `POST /api/search` → orchestrator → `SerpApiFlightsProvider`
- One-way international and domestic routes validated against the live API
- Direct and multi-stop offers mapped to shared `Flight` model
- Config already documented: `USE_MOCK_PROVIDERS=false`, `FLIGHTS_PROVIDER=serpapi`, `SERPAPI_API_KEY`, optional `SERPAPI_DEEP_SEARCH`

---

## Production improvements

- Date-time preserved as localized `YYYY-MM-DD HH:mm` strings (compatible with existing `Flight` fields — no model change)
- Currency defaults to EUR when budget currency is absent (avoids silent USD default from SerpAPI)
- Round-trip: capped return lookups via `departure_token` with outbound-only fallback on failure
- Structured SerpAPI logs; shared HTTP timeout handling

## Known limitations

1. **Round-trip return enrichment** — live `departure_token` return requests currently fail (HTTP 400) and fall back to outbound-only cards; RT **prices** from the initial round-trip response still display. Fix tracked for Sprint **11.4**.
2. **Flight card label** — UI hardcodes “Round-trip · per person” even for one-way (cosmetic).
3. **Datetime density** — full date-time on one line may be polished later.
4. **Dev hydration warning** — Next.js overlay on some pages (`SectionHeading`); page remains usable.
5. **Mock hotels / transport** — still mock and may appear beside live flights.
6. **Ops** — restart `npm run dev` after `.env.local` changes or the app may silently use mock flights.
7. SerpAPI remains a **configured live flights path**; Amadeus remains the longer-term production vendor option (ADR-036).

## Configuration (operators)

```env
USE_MOCK_PROVIDERS=false
FLIGHTS_PROVIDER=serpapi
SERPAPI_API_KEY=<secret — never commit>
SERPAPI_DEEP_SEARCH=false
```

`.env.local` is gitignored. Only `.env.example` is committed.
