## Major features

- End-to-end live hotels through existing architecture: UI → `POST /api/search` → orchestrator → `SerpApiHotelsProvider`
- Maps SerpAPI `properties[]` into shared `Hotel` model: name, price, currency, rating, stars, amenities, nights, location, `destinationId`
- Factory selection: `HOTELS_PROVIDER=serpapi` when `USE_MOCK_PROVIDERS=false` and API key is configured
- International destinations validated live (Paris, Milan, Rome, Tokyo, New York, and others)

## Provider architecture

```
Search UI
  → POST /api/search
  → SearchService
  → SearchOrchestrator
  → Provider Factory
  → HotelsProvider (mock | serpapi | booking stub)
  → shared Hotel model
  → UI
```

| Domain | Providers | Default |
|--------|-----------|---------|
| Flights | mock · serpapi (live) · amadeus | mock |
| Hotels | mock · serpapi (live) · booking (stub → mock) | mock |

No changes to `SearchOrchestrator`, `SearchService`, `SearchRequest`, `SearchResponse`, or the shared `Hotel` model.

## Known limitations

1. **Checkout date** — hotel search requires `returnDate` on the `SearchRequest`; one-way searches without checkout cannot query hotels.
2. **Child ages** — `SearchRequest` has no child age fields; adapter defaults each child to age `8` for SerpAPI `children_ages`.
3. **Rooms** — SerpAPI Google Hotels has no Glooconn `travelers.rooms` equivalent; rooms count is not sent to the vendor.
4. **Pagination** — page-1 results only; `next_page_token` not wired.
5. **Hotel images / GPS** — available on SerpAPI but not on shared `Hotel` model (ignored in adapter).
6. **Round-trip flights** — RT `departure_token` return enrichment still incomplete from v0.17.0 (outbound fallback).
7. **Mock transport** — buses and trains remain mock.
8. **Ops** — restart `npm run dev` after `.env.local` changes or the app may silently use mock providers.

## Configuration (operators)

```env
USE_MOCK_PROVIDERS=false
HOTELS_PROVIDER=serpapi
SERPAPI_API_KEY=<secret — never commit>
```

Optional (flights, unchanged from v0.17.0):

```env
FLIGHTS_PROVIDER=serpapi
SERPAPI_DEEP_SEARCH=false
```

`.env.local` is gitignored. Only `.env.example` is committed.
