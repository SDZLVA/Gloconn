# Glooconn v0.22.0 — Hotel Actionability + Cleanup

**Release date:** September 22, 2026  
**Branch:** `main`  
**Previous release:** [v0.21.0](./v0.21.0.md) — Recommendation Intelligence  
**Tests:** 717 passing · 0 failing  
**Security:** Baseline verified — **0** npm audit vulnerabilities; Next.js patched to 16.3.3

---

## 1. Release overview

v0.22.0 closes **Milestone 17 — Hotel Actionability** and the **17.9 Cleanup** pass.

Users can open a hotel from results, see richer property details, and follow safe external links (for example maps / booking). The release also hardens production hosting (CSP nonce on Vercel), seals sensitive property references, and cleans up the repo branch / CI / dependency security posture.

Users still see informational estimates only. No booking checkout, payment, AI/LLM personalization, or new travel providers.

---

## 2. Milestone 17 objective

Make hotels in search results **actionable** without turning Glooconn into a booking engine:

1. Open a hotel details drawer from result cards / packages
2. Show property context (including Google Maps where available)
3. Load property details through a server API with safe external links
4. Keep property identifiers sealed so raw vendor refs are not exposed in the browser

---

## 3. Hotel actionability

- **View hotel drawer** — open hotel context from results without leaving the search flow
- **Google Maps** — embed / maps links for property location when data is available
- **Property details API** — server route for hotel details (not client → vendor)
- **Safe external links** — outbound booking / maps URLs opened carefully
- **Card polish** — clearer hotel cards aligned with the MVP results UI
- **Package details UX** — improved package detail presentation alongside hotel actionability

---

## 4. Sealed property references

- Property refs use the **`gpref1`** sealed format
- Sealing depends on server-only **`PROPERTY_REF_SEAL_SECRET`**
- Clients receive sealed refs; raw vendor property identifiers stay off the wire where sealed

---

## 5. Production hardening (Milestone 17 carry-forward)

- **CSP nonce fix** — nonce propagation corrected so Next.js hydration works under Vercel CSP
- **Real-data replay mode** — internal validation helper for replaying live-shaped search data (blocked in production)
